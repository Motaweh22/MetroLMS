
### Summary of Disconnected Workflows
1. **End-to-End Quiz Grading & Certificate Lifecycle:** Backend implements `QuizDefinition` grading (`/quiz/submit`) and `CertificateRecord` (`/issue`, `/revoke`, `/verify/:code`), but the frontend neither submits quiz answers to `/quiz/submit` nor exposes UI for issuing/revoking/verifying certificates.
2. **Governance `PendingApproval` Execution Loop (`INV-R9` / `INV-R10`):** `ApprovalListView` and `ApprovalDecisionView` exist, but `executor_fn=None` turns approval into a no-op state flip, while `has_capability` blocks `assistant_admin` with 403 on write endpoints instead of creating `PendingApprovalRequest` (`202 Accepted`).
3. **Group QR Join & Delegated Authority Toggles:** Broken JSON key contracts (`enrollmentCode` vs `token`; `enabled` vs `capabilityKey`) break both features against the real Django API.
4. **Group Meetings Tab, Course Lab Reset & Comments Toggle:** Frontend calls mismatched/stubbed/missing endpoints (`PUT .../groups/:id` with `resources`, `POST .../reset-lab`, no-op `comments-toggle`).
5. **Group Member Removal (`D-07`) & Renewal Cycle Progression:** `AdminGroupMemberDeleteView` drops `removeCourseIds`, `renew_training_group` does not copy courses or create new cycle attempts, and `AdminGroupMaterialsView` leaks hidden (`isVisible: false`) materials in API JSON.
