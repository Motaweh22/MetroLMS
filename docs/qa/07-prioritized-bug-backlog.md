# MetroLMS — Phase 7: Prioritized Bug & Risk Backlog (`07-prioritized-bug-backlog.md`)

> **Classification Rules Applied Strictly:**
> - **Confirmed Defect:** Directly reproduced or verified in executed code, SQL Server database state, live HTTP calls, or built `frontend/dist/` output.
> - **Architecture Risk:** Confirmed design/scaling/config weakness verified in code/infrastructure that threatens stability, concurrency, or security under production load.
> - **Suspected Defect:** Highlighted in inspection where runtime verification in live browser was blocked or incomplete.
> - **Environment Blocker / Unverified Functionality:** Explicitly separated so missing runtime UI proof is never disguised as a pass.
