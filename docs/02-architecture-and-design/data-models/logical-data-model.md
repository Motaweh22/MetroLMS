## 1. Purpose, Boundaries & Stop Gate

- **Stage 2 Scope (`REV6` §12.K):** Engine-agnostic conceptual entity and relationship modeling across MetroLMS Domains `01`–`21`, independent of Microsoft SQL Server physical types, collations, indexes, or Django `models.py` implementations.
- **Explicit Exclusions:** Zero finalized attributes, zero primary/foreign key column names, zero SQL DDL, zero Django models/migrations, zero PostgreSQL assumptions, and zero UML diagrams (UML suite deferred post-Phase 5).
- **Evidence Classification Legend:**
  - `CONFIRMED` — Directly supported by accepted requirements or Owner-approved decisions.
  - `PROVISIONAL` — Supported by documented technical proposals or prototype DTOs, not yet Owner-approved for persistence.
  - `GATED` — Dependent on an unresolved Owner decision (`A-03a-1`, `A-03c-1`–`3`, `OD-API-01`–`04`) or incomplete domain (`Domain 16`).
  - `DEFERRED` — Explicitly deferred (`API-REC-06` `CL-03` signed URLs, malware scanning, retention/purge policies, `D3` NFR thresholds).
- **STOP CONDITION:** Per Owner governance, this document **stops before defining or freezing database-bound attributes**. Sections 5–7 present the **Owner Input & Field Review Package**, the **2026-11-14 Business Requirements Addendum**, and the **2026-11-14 Owner Decision Integration (`D-OWNER-REV-01`–`33`)** for explicit Owner review before `WP-5.5` or `WP-5.6`.

### 2.2 Explicitly Excluded Non-Persistent / Runtime / Computed Concepts
To avoid polluting the logical database model with UI/runtime artifacts, the following domain-doc concepts are **NOT** modeled as database tables:
- `SessionEpoch`, `RolePreviewState`, `DeveloperOriginSnapshot` (in-memory/DEV-only browser state — `Domain 01`, `03`).
- `SubstantiveFingerprint` (computed diff result in `LLD-002` — `Domain 07`).
- `GroupMetrics`, `CohortSummaryMetrics`, `AssignedCourseProgressMetric`, `TraineeGroupMetrics`, `ComputedAttemptProgress` (derived aggregations — `Domains 13, 17`).
- `PublicSupportContactsResponseDTO`, `SessionUserDTO`, `TraineeGroupItemDTO` (API projections/DTOs — `WP-5.3`).
