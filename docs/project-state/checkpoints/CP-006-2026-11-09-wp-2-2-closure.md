## 9. Architecture / Contract Changes

- **API Contract:**
  - `DELETE /api/admin/groups/:groupId/members/:userId` now accepts an optional JSON body:
    ```json
    {
      "removeCourseIds": ["CRS002"]
    }
    ```
  - When omitted (`undefined`) or empty (`[]`), the default is to retain all group courses as continuation grants (`D-07`).
- **Grant Provenance Format:**
  - Continuation grants use `sourceId: 'self:continued:${groupId}:${attemptId}'` with `kind: 'self'`, `convertedFromGroupId: groupId`, and `attemptId` pointing to the existing attempt.

---

## 10. Requirements or Business Rules Clarified

1. **Continuation Grant Lifecycle:** When converted to `self:continued:...`, the grant's `kind` is `'self'` and group-specific deadline constraints no longer apply.
2. **Global Course Count Consistency:** `course.enrollmentCount` is decremented only when a trainee has no remaining active grants for that course.
